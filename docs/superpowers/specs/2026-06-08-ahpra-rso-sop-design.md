# AHPRA RSO SOP — Design Spec

**Date:** 2026-06-08
**Author:** GP Link Operations
**Format:** Scribe guide, placed in admin AHPRA stage guides section
**Audience:** RSOs — onboarding training and day-to-day reference
**Tone:** Practical and direct
**Terminology:** "RSO" throughout

---

## Scope

Covers the AHPRA stage (Australian Health Practitioner Regulation Agency) — registration, practice pack documents, SPPA-00 lifecycle, and AHPRA correspondence handling. Does not cover manual stage overrides or support ticket handling (separate SOPs).

## Structure

### Section 1: Overview & Quick Reference
- What AHPRA is, the 3 substeps (Account, Application, Status)
- Prerequisites: AMC verified + placement secured
- The 5 practice pack documents at a glance
- External portal URL
- Quick-reference table

### Section 2: Substep Walkthroughs
- 2a. Create Account — AHPRA Online Services setup
- 2b. Application — begin specialist registration application
- 2c. Awaiting Outcome — monitoring AHPRA processing

### Section 3: Practice Pack Documents
- 3a. Offer / Contract
- 3b. Supervisor CV
- 3c. Position Description
- 3d. Section G (auto-delivered)
- 3e. SPPA-00 (full lifecycle with conflict scan, corrections, alt supervisor CVs)

### Section 4: AHPRA Correspondence
- How AHPRA emails are detected
- Officer tracking
- Action items with deadlines
- Response types and how to handle each

### Section 5: Communication Playbook
- Nudges, WhatsApp, email

### Section 6: Support Tickets
- Pointer to separate SOP

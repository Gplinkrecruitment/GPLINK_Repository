The rules
TriggerMarking any application "Hired" on a job. One confirmation dialog first: "4 other GPs are still active on this job — send them the redirect email?" so nothing goes out by surprise.
Who gets itEvery other GP on that job in Shortlist, Applied or Interview. GPs already marked "Not proceeding" earlier are skipped (they were already told).
AlternativesPicked per GP from live open jobs: same state/region first, then similar expected income (billing split / earnings range). Up to 3; jobs the GP already has live are excluded. If nothing similar is open, the email still goes out — with "Hazel will match you personally" instead of cards.
ToneSame design language as the match email, but no 98% stat and no countdown — it leads with respect, then opens the next doors.
In the appThe expired match card is removed from My Practice; the alternatives appear as normal roles they can view. A bell alert mirrors the email.

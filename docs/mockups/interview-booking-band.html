Interview booking band — proposed

The band that sits under a candidate card while they are at Interview. Same .cr-strip component as the action band already on main, so nothing new to learn. Every state below is a real state the data can already be in.

State AWaiting on the practice for times

Owner correction: the practice's own approval screen cannot produce this — it validates the windows and 400s with windows_required before changing anything. It is only reachable when STAFF record an acceptance the practice gave by phone or email. That route now emails the practice for availability automatically, so this state always arrives with a request already outstanding rather than as a dead end. Nothing the doctor can do yet, so the band offers no doctor action at all.

The nudge system. A cron mirroring the existing post-interview chase: if times exist, nothing is booked and the doctor was invited more than 48h ago, send a booking email deep-linked to the same slot picker. Repeat every 48h, cap at 3, then stop emailing and raise it on the attention tiles instead — an automated chase that never gives up just trains people to ignore it. Nudge doctor to book fires the same email by hand, and the count is shown so you never nudge someone who was nudged an hour ago by the cron. Needs two new columns (booking_nudge_count, booking_nudge_last_at); the send-once invite stamp stays untouched so the two can't fight.

State FBlocked — identity not revealed

A real gate that exists in the code today: the booking invite refuses to send unless revealed === true, because it names the practice. Both real accept routes DO reveal, so this is now unreachable going forward — but the kanban drag could previously drop a card straight into Interview with no reveal and no job, which is how the orphaned row on the dashboard got there. That drag is now gated (job_required). The band keeps this state as a safety net for rows already sitting in it, because the alternative is what happened before: a silent skipped: 'not_revealed' and a doctor told nothing at all.
